# Statin Adverse Events Analysis

Do lipophilic statins (atorvastatin, simvastatin) have a higher share of
muscle-related adverse event reports than hydrophilic statins
(rosuvastatin, pravastatin)?

**Data:** FDA Adverse Event Reporting System (FAERS) via the openFDA API
**Tools:** R (jsonlite, dplyr, ggplot2)
